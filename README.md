## 🚀 Quickstart

Prerequisites: Node 18+.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # runs prebuild → fetch-stats, then tsc + vite build → dist/
npm run preview  # preview production build
```

Update DSA stats manually:
```bash
npm run stats    # node scripts/fetch-stats.mjs → src/data/stats.json
```
If LeetCode/GFG are unreachable, the script keeps the existing `stats.json` intact.

## 🛠️ Customization

1. **Profile / links:** `profile` object in `src/data/content.ts` (name, email, phone, GitHub, LinkedIn, resume path).
2. **Skills / projects / experience:** edit `skillGroups`, `projects`, `engineeringFocus`, `experience`, `certificates`, `education` in the same file.
3. **Resume:** replace `public/Koushik_Korada.pdf` (keep filename or update `profile.resume`).
4. **Stats usernames:** `LC_USERNAME` / `GFG_USERNAME` at top of `scripts/fetch-stats.mjs`.
5. **Deploy:** `npm run build` → deploy `dist/` to Vercel / Netlify.
